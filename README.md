# Uday — Portfolio

Personal portfolio built with Nuxt 3, Vue 3, TypeScript, Tailwind CSS and Lucide icons.

## Edit content
All text, projects, services and experience live in `data/portfolio.ts`.
Search for `TODO` to find the placeholders to replace.

## Run locally
```bash
npm install
npm run dev        # http://localhost:3000
```

## Deploy
```bash
npm run generate   # static site in .output/public
```
Deploy to Vercel, Netlify or Cloudflare Pages: import the GitHub repo, and the Nuxt preset is detected automatically.

### GitHub Pages
```bash
npm run deploy     # builds and pushes to the gh-pages branch
```
Live at https://udayaa11.github.io/uday-portfolio/
